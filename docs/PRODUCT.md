# v0.4 · 16题与六维能力图

## 玩家体验

外部收款发链接，网页无支付与付费墙。首页 → 16道独立情境题 → 角色揭晓 → 六维能力图 → 鬼灭侧写 → 留言 → 保存角色卡。原12题/48选项正文保持不变，新追加q13《鎹鸦带错的路》、q14《庙会上的空位》、q15《练不成的那一招》、q16《谁来拿主意》，总计64选项。

按用户要求，结果页不展示“为什么是这个角色”、过往答案引用、人物信息与原创联想的解释性旁白、“匹配怎么算”入口。原始支持证据仅供内部规则调试，不渲染给玩家。结果页不再展示带元说明的角色基本信息段落；保留原创侧写和留言。算法与来源只留在开发文档。

## 六维能力

六维：行动力、洞察力、应变力、意志力、共情力、守护力。每个选项提供6个0—3的编辑输入。每道题先按该题各维度最小/最大值归一化，随后对有效题平均映射到30—90；同题同分不计入该维度，无有效题时回到60。图表是本次娱乐冒险设定，不是现实能力测量。

不按角色分配固定图形，同答案即同六维，不同答案可改变图形。隐藏继国缘一也不自动满分，使用同一份实际选择六维。SVG与PNG通过js/radar.js共享六角点位，页面显示六个名称与数值；PNG900×1600包含同一图形及数值。

## 角色池与隐藏

主角4位：炭治郎、祢豆子、善逸、伊之助。柱8位：义勇、胡蝶忍、炼狱杏寿郎、天元、蜜璃、无一郎、小芭内、实弥。反派4位：无惨、猗窝座、童磨、黑死牟。另有隐藏继国缘一。

常规16角色按选项3/2/1支持分累计并按各角色理论分值范围归一化，不先分阵营。接近阈值0.04；同分稳定ID排列，页面保留接近/并列提示，无准确率与科学测评承诺。

彩蛋独立触发率0.1%（1/1000），crypto无偏整数；每次完成只抽一次，导出不重抽，重测可重抽。隐藏页与卡片说明独立彩蛋、保留常规角色名称，不以稀有人格包装。首页只显示隐藏问号。概率为配置基础率，不保证真实用户批次中角色频数排序。

## 呈现与工程

角色归原作，情境、结果文案和山谷SVG为原创，无官方立绘、截图、台词、音乐、Logo；不暗示授权。简短非官方与娱乐说明保留页脚。角色事实参考官方人物介绍，支持映射与六维均为编辑设定，未经心理测量验证。

原始参考：https://kimetsu.com/anime/mugenjyohen_movie/character/ 、https://kimetsu.com/anime/character/risshihen/ 、https://kimetsu.com/anime/yukakuhen/character/?id=05 。

答案仅存内存，刷新和重测清空。无账号、埋点、答案上传或访问鉴权。静态源码公开可见，不能承诺隐藏防拆、结果防篡改或次数限制。

运行npm start；npm test生成覆盖样本；npm run test:browser做浏览器验证；npm run review:content导出16题与64选项映射。npm run build仅复制7个运行文件到dist，netlify.toml保持Node22与静态发布。原型分支未合并main，Netlify已绑定时推送可能触发构建，未获站点状态不宣称公网部署成功。
