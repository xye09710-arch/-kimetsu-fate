# v0.3 · 16位常规角色与隐藏彩蛋

## 产品流程

外部先收款发链接，网页提供全部娱乐体验，不接支付、不设付费墙、不加收抽取费用。打开页面 → 12道确认情境题 → 常规角色或隐藏相逢 → 完整原创解读 → PNG收藏卡。重测清空内存并重新抽取，刷新回到首页；无账号、持久化和答案上传。

12题与48个选项沿用已确认原文。第1—6、9—11题来自D老师第二轮稿；第7题《还有一个办法》、第8题《那条没能追上的山路》、第12题《先把门锁上》。独立情境不必串成同一经历。

## 确认名单

主角4位：灶门炭治郎、灶门祢豆子、我妻善逸、嘴平伊之助。

柱8位：富冈义勇、胡蝶忍、炼狱杏寿郎、宇髓天元、甘露寺蜜璃、时透无一郎、伊黑小芭内、不死川实弥。

反派4位：鬼舞辻无惨、猗窝座、童磨、黑死牟。

隐藏1位：继国缘一。不参与常规排名，首页只显示“？隐藏角色”。香奈乎、珠世、累已移出，不保留失效映射。

## 常规匹配

每选项为3位常规角色提供3/2/1编辑支持分；每个角色按自身理论分值范围归一化，再比较16位常规角色。没有阵营门槛。前两位差<0.04提示接近；精确同分按稳定ID展示，并明确并列。匹配不是随机抽卡，同答案常规结果固定。

结果展示最多3条真实答案支持证据。角色事实与原创联想分开，反派结果不推定玩家冷酷或认同伤害行为。无惨、童磨在当前题目中的依据较弱，只呈现掌控或旁观的一小块重合。原型用于娱乐，不宣传科学准确率，不把支持度转成百分比或人群排名。

## 隐藏机制

默认每次完整答题独立触发1/1000，即0.1%。这是最低的配置触发率；在6万固定采样中也低于任一常规角色的频率。常规结果取决于真实用户答案，不能保证任意一批人的实际次数排序。需要固定库存或按批次配额时，必须另设计服务端系统，当前不宣称具备此能力。

浏览器crypto.getRandomValues产生无偏整数票号，通过拒绝采样移除取模尾部偏差。票号0触发彩蛋，其他票号展示常规结果。完整答题时只抽一次，下载、关闭对话框不抽取；重测可重新抽取。页面/图片均明确彩蛋独立于性格匹配，隐藏页保留常规匹配及其真实证据，不杜撰缘一的答案依据。

继国缘一使用金色边框和专属揭晓段落，无强制动画；默认尊重减少动态效果设置。首页不公开名字不等于技术保密：这是静态娱乐原型，源码可见，无防篡改、次数限制或付费鉴权。没有额外付费抽取、保底或奖励兑换。
