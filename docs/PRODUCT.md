# v0.5 · 深度人物报告与角色专属视觉主题

## 流程与不变量

首页 → 原有 16 道题 / 64 选项 → 角色揭晓 → 六维雷达与六项动态解读 → 与角色的相似之处 → 内在矛盾 → 鬼灭世界原创情境 → 留言 → 保存角色卡。

`js/data.js` 与 `js/scoring.js` 保留 v0.4.1 原样：16 常规角色按支持分归一化，稳定并列与接近提示；六维逐题归一化后映射到 30–90。隐藏继国缘一独立无偏抽取，1/1000；常规结果保留，六维不自动满分，导出不重抽。全部 17 张肖像及紫藤夜行首页保持不变。

不展示逐题答案、过程引用、支持证据或算法说明入口，无支付墙和外部模型服务。答案仅存当前页面内存，刷新/重测清空，无上传、埋点或账户。

## 动态内容

`js/report.js` 独立于评分。每维由一段针对该维度及数值区间的原创解读，加一段角色独有的行为/世界观语境构成。低档 `<50`，中档 `50–69`，高档 `≥70`；边界与 0/100 的自然表述有测试。三档是编辑叙事分段，不是心理学阈值或人口排名。相同输入确定性输出，不进行模型请求。

每位角色有六条独立语境，共 102 条；与三个区间组合形成 306 种解读。六维同一角色不同组合可改变解读，人物核心段落保持稳定，避免为了迎合分数篡改角色事实。单维约 80–120 字；相似处 200–300 字，矛盾 150–250 字，命运情境 150–200 字，段落分隔便于长文阅读。

炭治郎的同情与责任、忍的药理与复仇、天元对忍者牺牲秩序的反抗、蜜璃的自我接纳、岩胜的比较与执念等各自展开。反派的求生、比较、空洞等不能被美化成玩家的道德评价；童磨缺乏共感是虚构人物设定，不能由分数推断现实情感。缘一的相似处明确说明独立彩蛋；命运情境均标注原创，不冒充原作剧情或台词。

## 视觉与导出

17 个角色 ID 各自绑定 `bg/panel/accent/secondary/text/muted/line/fill`。根据现有肖像的红金、粉、黄黑、青蓝、紫、绿白等方向调色，深底浅字；结果和导出弹窗局部 CSS 变量作用域不影响首页。SVG/Canvas 共用主题参数与六角几何；图上保留名称和数字，不只靠颜色区分。无持续动画，无整套肖像预加载。

手机单列六维解读，正文 16px、行高 2.05，段落间留白；宽屏六维解读两列。肖像完整展示，不将长文压到图片上。失败时网页显示提示、PNG 以角色名占位，报告与导出仍可使用。

PNG 固定 900×1600，保留角色名、原始肖像、实际六维、简短侧写与必要彩蛋/接近提示。使用原有短侧写，不复制长篇报告；每个文字区限制宽度/行数，超长截为省略号，避免与页脚重叠。标题与图表沿用角色配色。
