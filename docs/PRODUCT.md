# 《鬼灭命运录》第一版产品草案

## 定位与范围

有故事感的娱乐测评，测评为主、故事为奖励。目标：用户在3—5分钟内完成12次选择，先看到明确阵营和身份，再理解结果与自己选择的关系，最后带走一张原创身份卡。无登录、付费、官方角色匹配、对话养成或双结局。第二版是否增加故事选择，由第一版体验反馈决定。

## 页面流程

首页交代时长、题量、身份数量和非官方定位。每页一道情境题，主动点击下一题；未选禁用前进，可回退修改，保留后续已有答案。12题完成后揭晓阵营，用户主动翻开档案。档案依次呈现身份判词、实际选择证据、四类选择次数、能力、代价、牵绊和三段命运短篇。最后保存PNG或重测。重测清空全部内存，刷新也清空。

## 题库与评分

js/data.js 为唯一执行数据源：q01—q12，每题A—D四项。全题正文、选项、阵营权重和倾向映射均可直接审阅。四类行动方式是守护、谋略、执念、自主；每项计入一个倾向一次，同时提供独立阵营证据 +2/+1/-1/-2。正值偏鬼杀队，负值偏鬼阵营。

12项阵营证据相加，正数进鬼杀队，负数进鬼阵营；恰好0时采用最后一题阵营证据方向。绝对值≤3时，揭晓和档案都显示“交界、微弱倾向”。不显示人格好坏或人群百分位。

四类倾向按实际选择次数累计，最大值决定该阵营下的身份；最大值同分时，采用从后向前遇到的首个并列倾向。固定规则、无随机、末题仅在同分时裁决。展示次数之和为12，非能力评分。该规则是叙事路由草案，不具有心理测量效度。

题目选项当前一项只绑定一种倾向，映射较直观；后续可依据用户反馈改进题目，避免用上线后临时随机或强制配额平衡结果。抽样分布只能检查算法和覆盖，不代表真实用户分布。

## 八种原创身份

|倾向|鬼杀队|鬼阵营|
|---|---|---|
|守护|守灯人 / 余烬织幕|藏火之鬼 / 灯芯藏焰|
|谋略|听隙师 / 静隙回响|镜隙之鬼 / 折镜迷廊|
|执念|刻誓者 / 回纹刻印|缄信之鬼 / 墨痕封声|
|自主|渡风客 / 折风踏渡|无岸之鬼 / 游潮换影|

每份包含判词、能力机制、代价、牵绊和完整三段短篇。鬼阵营描写欲望与边界，避免将其直接等同于现实恶人；鬼杀队也有局限与成长。所有人物均为原创，不冒充原作世界的正式设定。

## 视觉与交互

深蓝绿长夜、暖金灯火、浅米色正文；中文衬线标题与易读正文组合。原创SVG以山谷、弯月、两条小路和灯火表现两种去向，身份卡复用同一视觉。无官方人物服装、角色脸、图案标识或音频。

手机单列、桌面首页双列；按钮至少44px，原生键盘焦点、选中状态、进度条语义、跳过导航和 reduced-motion 支持。页面切换聚焦主内容，答案点击不强制换题。PNG通过可关闭的原生对话框预览，可下载或手机长按保存，生成失败给出可见提示。

## 验收口径

12题可完成；返回可改且不重复计分；八种身份均可触达；同一答案结果固定；同分有明确规则；档案证据来自实际答案；每种身份有完整短篇；手机无横向溢出；导出900×1240 PNG；重测和刷新清空。发布前补充真机保存和实际阅读反馈。
