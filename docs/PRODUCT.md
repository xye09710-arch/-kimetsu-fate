# v0.2 产品与内容决策

## 当前目标

用户最终要看到“我最像哪个鬼灭角色”。不再输出v0.1原创身份、专属能力或平行人生短篇，也不采用先分鬼杀队/鬼再定身份的规则。

流程：首页说明与角色名单 → 12道独立情境题 → 具体角色结果 → 3条实际回答支持证据 → 人物侧面 → 相似与差异 → PNG角色卡/重测。

题目定稿：第1—6、9—11题沿用用户提供的D老师第二轮稿；第7题为《还有一个办法》、第8题为《那条没能追上的山路》、第12题为《先把门锁上》。通过段落显示保持原文，不自行再次润色。第8题明确有半年训练经历，第12题明确假设已变成鬼；开场说明各题不必连续，避免身份矛盾。

## 角色池

鬼杀队：炭治郎、善逸、伊之助、义勇、胡蝶忍、炼狱杏寿郎、香奈乎。鬼：祢豆子、珠世。反派鬼：猗窝座、黑死牟、累。

采用有限候选池，而非宣称覆盖全部角色。当前题目缺少足够的支配欲、情感疏离等证据，不为了凑反派数量加入无惨或童磨。黑死牟、累的结果也仅联想局部动机，明确说明不等于认可原作行为；不以温柔、慎重或愿意求助排除鬼角色。

## 评分与结果

48选项各为3位角色提供3/2/1支持分。每位角色按自身在题库中的理论最小—最大总分归一化，避免单纯因获得映射机会多而得分高。所有12题一起比较12位角色，无阵营分和末题裁决。

最高两位归一化支持度差<0.04时显示接近提示；相差≤1e-12视为并列，保留并列说明。仅为稳定显示，精确同分按稳定角色ID字典序排列，不声称排列靠前者更相似。页面和PNG都显示第二位接近/并列信息。不展示内部数值为百分比、准确率或人群排名。

支持分、0.04阈值和角色解读均为编辑假设，非官方设定、非真实角色答题记录、未经心理测量验证。题库对关系、求证与风险覆盖较多；冷漠、支配、竞争等特征覆盖不足。抽样分布用于发现死结果和规则异常，不代表真实用户分布或有效性。

证据展示：对当前角色有正支持分的实际答案，按贡献排序选择最多3条。每条显示题目、用户选项和该动作的有限解释，不杜撰选择，不把一般行为直接解释成角色的极端经历。

## 保留的交互与部署

移动端单列、桌面双列；答案选中可见、禁止空答、可回退编辑。进度条使用实际已答题数，页面切换聚焦主内容，图片通过原生dialog预览。刷新和重测清空；不持久化、不传输答案。

运行、构建与Netlify目录维持静态方案。只更新独立新仓库的原型分支，不改其他项目，不合并main。Netlify若已绑定分支，后续推送由其自动部署；无站点访问时不宣称部署完成。
