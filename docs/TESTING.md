# v0.5 验证记录

## 复现

Node.js 18+（推荐 22 LTS）。站点没有运行依赖。

1. `npm test`：原评分回归，随后报告/主题单元测试；前者产生忽略目录 `test-results/fixtures.json` 供浏览器使用。
2. `npm start`：保持静态服务运行。
3. 另一终端 `npm run test:browser`：需要 Playwright 与 Chrome。Windows 安装和 CHROMIUM_PATH 设置见 README。本次 Linux 使用 `/usr/bin/chromium`。
4. `npm run build`：`dist` 包含 25 个运行文件，新报告模块已加入。

本次环境：Node.js 24.22.1、系统 Chromium、Playwright headless。测试输出与截图保留在本地忽略的 `test-results`，不将生成物加入版本控制。

## 原有不变量

`js/data.js`、`js/scoring.js`、`assets` 与 v0.4.1 基线无差异。原评分测试仍运行 60,000 组固定种子样本：16 常规角色均可达，并列 1,733 组，接近 21,368 组。另测输入拒绝、理论归一化、确定性、顺序不变性、六维范围/手算、独立彩蛋边界；这些是规则覆盖，不是用户匹配准确率。

浏览器逐题核对原文与选项，核对常规与隐藏六维点位，回退后重算、刷新与重测清空；隐藏结果保留常规角色，重复导出不重抽。没有生产用测试入口或结果强制覆盖参数。

## 新增内容与主题测试

`tests/report.cjs`：17 个角色 ID 一一覆盖，无共享主题或共用整段相似处；相似处 200–300 字、矛盾 150–250 字、原创情境 150–200 字。六维共有 102 条角色语境 × 三档 = 306 种组合，最终每项 102–118 字（含标点）。

测试 0、49、50、69、70、100 分，核对低/中/高档分界、同输入确定性、不修改输入、拒绝非法数值。额外搜索实际可达的同角色不同答案组合，验证跨档时解读确有差异。检查主题正文、次要字、主色与辅色在背景/面板上均达到 WCAG AA 普通文字 4.5:1；图表另保留名称与数字。

`tests/browser.cjs`：全部 17 位角色的 DOM 报告、六段动态文字、章节顺序、角色 ID、CSS 主题和 SVG 主题与内容配置一致；每个角色结果在 320/390/768/1280px 检查无横向溢出、六维段落不溢出、正文 16px。完整答题、原图解码、原有六维点位及标签不重叠断言继续执行。新容器变窄时曾发现手机雷达标签与数值间距不足，已将 SVG 数值间距改为 30 单位。

PNG 检查真实 900×1600 解码与下载，核对文字真实测量边界位于边框以内、文字块彼此不重叠、短侧写不侵入页脚，核对六维名称、文字主题色与必要说明。额外拦截肖像请求，验证网页显示失败提示且仍能导出带角色名占位的 PNG。重测回首页后，背景样式与原首页一致。

## 人工检查与限制

检查已生成的手机结果长图及反派分享卡，确认肖像完整、正文分段、短卡留白与主题协调。自动化不证明全部人物解释都获得原作读者认可，内容仍建议由熟悉原作的编辑复核，特别是后期剧情及反派伦理边界。

仍需 iOS Safari、Android Chrome、微信等内置浏览器真机验证长按/下载、系统字体换行和低端设备体验。未验证公网 Netlify 部署；没有真实用户心理测量验证。静态源码无法保护隐藏角色秘密、结果防篡改、访问鉴权或次数配额。
