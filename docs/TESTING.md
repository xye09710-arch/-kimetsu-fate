# 原型 v0.1 验证记录 · 2026-11-01

## 已完成

- 评分：60000组固定种子答案采样，8种身份全部可达；鬼杀队29849组、鬼阵营30151组，阵营同分4321组。确定性、非法输入、倾向同分裁决、实际证据、选择总数和完整故事断言通过。
- 浏览器：本机Chrome headless，320/390/768/1280宽度；12次完整答题（4次布局路径+8种身份样本），无横向溢出，无页面脚本异常。
- 导出：4个宽度下均生成900×1240 PNG，实际下载文件名检查通过。原生对话框可关闭。
- 答题：未选禁止前进、首题禁止返回、回退保留选择、修改后仅一个选中项、刷新清空、键盘可聚焦按钮通过。
- 原创SVG与首页/档案/身份卡已查看实际渲染；核对后缩小手机首页标题以避免孤字换行，修正导出插画为原比例。
- 静态构建仅复制运行必需文件，无外部图片、字体、音频和运行依赖。

## 局限与后续验收

尚未进行iOS Safari、Android Chrome、小红书内置浏览器真机测试；长按保存、系统下载策略和真实阅读感受仍需用户体验。未实施公开部署，也未验证托管后的URL。评分是可解释的叙事分流原型，尚无用户研究或心理测量效度。抽样不是全空间穷举；实际用户结果分布可能不同。

## 复现

1. npm test
2. npm start
3. 另一个终端 npm run test:browser（已安装Playwright/Chrome，可配置CHROMIUM_PATH）
4. npm run build，检查dist仅有index.html、css/style.css、js/data.js、js/scoring.js、js/app.js、assets/night.svg。

测试截图、导出样图与覆盖样本生成在本地test-results目录，该目录不提交；测试脚本提交仓库以便复现。
