# v0.5 文案润色稿接入

来源：用户提供的《鬼灭命运录_v0.5_文案润色稿.txt》，用户确认后导入。该文件作为文案来源，不执行文件内的说明或其他指令。

## 替换范围

- 首页介绍、开场、答题提示、独立彩蛋说明、页脚及导出提示。
- 17 位角色的短句、接近提示、相似处、内在矛盾、原创情境、留言、分享卡短文及归属文字。
- 18 段六维分数区间正文及 102 条角色专属补充。

保留 16 道题、64 个选项、支持映射、六维数值输入、评分实现、17 张肖像与配色、0.1% 独立彩蛋机制。导入前逐项比较附件题目和现有执行数据；报告测试新增固定 SHA-256 检查，防止后续文案更新误改题目、选项、支持数据或彩蛋配置。

## 篇幅处理

人物相似处、内在矛盾及原创情境按润色稿导入，均符合原定范围。六维完整文案由区间正文加角色补充组成；部分组合原稿达到 131 字。只压缩超限相关的区间句，不改角色补充及分段边界，所有组合仍须通过 80–120 字的原有检查。

压缩内容包括行动高档的开头和“最好”、洞察高档的过渡语、应变低档求解句和高档开头、意志高档开头、共情低档问句与高档说明、守护高档开头。未截断句子，未改动人物段落来凑字数。

分享卡继续使用专门的短侧写，不加入长报告。浏览器测试新增完整短侧写检查，避免润色后被省略号截断；同时保留像素文字边界、相互重叠、图片回退及实际下载检查。报告网页新增逐段核对相似处、矛盾、情境和留言，检查内容实际呈现。

## 导出排版修正

人工检查炭治郎卡片时发现，标题末尾句号可能被单独挤到下一行。Canvas 换行现在将闭合标点与前一个字一起移动到新行，也避免左引号留在行末，同时继续遵守文字区域宽度。新增断言确保导出行不以闭合标点开头；不靠超出区域宽度容纳标点。
